## Development

### Prerequisites

- Node.js 20 or higher
- pnpm 8 or higher

### Local Development

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build

# Build static export for GitHub Pages
NEXT_PUBLIC_BASE_PATH=/agentic-services-platform-beads pnpm build
```
